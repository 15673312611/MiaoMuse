剧本正文

秦川在旧宅为母设灵堂，陈虎带人秦沈临风之前前来灭口。秦川跪在遗像前未动，陈虎端翻香炉挑衅。香灰落地瞬间，秦川胸口的龙纹玉佩彻底碎裂，金色纹路蔓延其身，一道古老声音宣告“龙主归位”。秦川轻易废掉打手，震慑陈虎，眼神冰冷地说学会了不再跪。

情节1：夜里，秦川回到秦家旧宅，为母亲设置了简单的灵堂，独自守灵。

情节2：灵堂外传来剧烈的砸门声，打破了夜的寂静，预示着麻烦上门。

情节3：陈虎带着一群林家打手强行闯了进来，声称奉沈临风之命，要让秦川今晚消失。

情节4：秦川背对众人，依旧跪在母亲的遗像前，仿佛对身后的危险毫无察觉。

林氏集团发布会上，沈临风正宣布与林雪订婚，大屏幕突然播放三年前车祸真相视频，证明肇事者是沈临风而非秦川。全场哗然之际，秦川黑衣现身会场，直面沈临风，当众揭穿其罪行，宣告复仇开始，令林雪脸色惨白。

情节1：林氏集团召开发布会，江城媒体云集，沈临风与林雪即将宣布订婚消息。

情节2：沈临风在台上春风得意，正式宣布沈林两家联姻，会场一片祝贺之声。

情节3：突然，发布会现场的大屏幕黑屏，随后开始播放一段清晰的监控录像。

情节4：录像内容正是三年前那场改变秦川命运的车祸，画面显示真正的驾驶者是沈临风。

第5章  龙主
沈临风欲令保镖动手，会场外突然涌入佩戴龙形徽章的黑衣人，向秦川跪拜高呼“恭迎龙主”。秦川揭露自己龙门之主的身份，林雪交出沈临风策划放弃抢救的录音证据。秦川握碎录音笔，当众宣布“沈家，今晚除名”，展开终极复仇。

情节1：沈临风恼羞成怒，命令现场保镖对秦川动手，试图控制混乱局面。

情节2：保镖刚欲行动，会场外迅速涌入一队气势森严的黑衣人，制服统一。

情节3：这些黑衣人胸口均佩戴着精致的龙形徽章，他们行动整齐划一，训练有素。

情节4：为首的黑衣人径直走到秦川面前，单膝跪地，声音洪亮地高呼：“恭迎龙主出狱！”
