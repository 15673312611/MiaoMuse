第5章  龙主

277字

沈临风命令保镖动手。可保镖刚迈出一步，会场外便涌入一队黑衣人，胸口全都佩着龙形徽章。

为首男人单膝跪地，声音震动全场：“恭迎龙主出狱！”

林父手里的酒杯摔碎。江城上流圈无人不知龙门，却无人见过龙主。传闻龙主一句话，可以决定一座城的生死。

沈临风脸色铁青：“不可能！他只是秦家弃子！”

秦川走到他面前，语气平静：“秦家弃我，龙门收我。沈临风，你欠我的，从我母亲开始还。”

林雪冲上来拦住他，颤声说放弃抢救书不是她签的。她递出一段录音，里面传出沈临风的声音：“老太太死了，秦川才会彻底疯。”

秦川握碎录音笔，眼底再无温度。

“沈家，今晚除名。”
